Subsystem architecture · the nervous system

The Event Bus is how they talk.

No agent calls another directly. Every action is an event published to a topic; interested agents subscribe. That's what makes the college observable, replayable and decoupled — you can pause, swap or add an agent without rewiring the rest.

Delivery & guarantees

What the bus promises.

Ordered per student

Events for one learner are delivered in order (keyed on subject), so an agent never sees an exam result before the lesson that caused it.

At-least-once + idempotent

Delivery retries on failure; handlers are written to be idempotent on id, so a redelivery is harmless.

Append-only audit

Every event is persisted immutably. The whole college is a replayable log — full tracing via traceId.

Replayable

Re-running the log rebuilds any agent's state from scratch — the basis for debugging, rollback & "what changed".
