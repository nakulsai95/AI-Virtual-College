How it applies

Three swaps, one switch.

1 · Token injection

The palette writes CSS custom properties on :root — --accent, --bg — and the whole UI recolors with a transition. No re-render.

2 · Term substitution

Every themed string carries a data-term key; the engine fills it from the record. "Principal" becomes "Headmaster" or "Commander" in place.

3 · Persona swap

Each role binds to the theme's persona set — avatar & voice — so the same Faculty Agent reads as a sensei or a slayer-corps master.
