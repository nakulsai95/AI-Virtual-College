Component architecture · 06 of n

The Registrar is the state store.

Every agent acts on a shared picture of you — what you've mastered, when you showed up, how you're trending. The Registrar owns that picture. It logs attendance as the college's heartbeat, keeps the transcript, and serves the student model that is the environment's state, sₜ.

role=records + student model owns=attendance · transcript serves=state to all agents attendance=heartbeats
Attendance as heartbeats

Showing up is a signal.

Paperclip's agent heartbeats become class attendance. Scheduled sessions produce presence events; presence over time produces momentum, which feeds the reward loop.

1
ScheduleSessions are placed on the academic calendar per the curriculum.
2
Log presenceEach session attended (or missed) is recorded as an event.
3
Derive momentumStreaks & recency roll up into a momentum score.
4
Feed the loopStalled momentum becomes a small teacher penalty + a Counselor nudge.

Why the Registrar is read-heavy

Faculty, Examiner, Guide and Counselor all observe before they act. Centralizing state in the Registrar means every agent sees the same sₜ — no drift, one truth.

one student model · many readers · one writer
