Subsystem architecture · the substrate

Any model. The right tools, auto-wired.

Two registries sit beneath every agent. The LLM Router backs each agent with a model you choose. The MCP Registry mounts the tools a subject needs — a coding course brings a Python sandbox online without anyone lifting a finger.

Half one · LLM Router

Every agent names its model.

The Principal assigns a model per agent at hire; it's swappable anytime. The router handles fallback & meters spend against the budget.

What the router does

One complete() interface for all agents. Per-agent model binding, automatic fallback on error, retries, and a cost meter that emits budget.threshold as an agent nears its cap.

agent → complete(prompt) → router → provider
