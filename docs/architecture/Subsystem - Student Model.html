The mastery representation

Per-concept, with decay.

Why per-concept, not per-course

Mastery lives at the concept grain so the Provost can pinpoint which idea didn't land, the Examiner can test gaps, and adaptive difficulty can target the weak cell — not the whole subject.

conceptId → { level, confidence, lastSeen }

Decay drives revision

Each cell's effective level decays with time since lastSeen. When it dips below a bar, the Registrar emits a revision cue — this is the engine behind spaced repetition.

effLevel = level · decay(now − lastSeen)
