A teacher is an RL agent.

Faculty aren't scripted tutors. Each one is a reinforcement-learning agent: its policy is an LLM steered by a teaching methodology, its environment is you, and its reward is whether you actually learn. Here's the anatomy of one.

policy=LLM + methodology reward=your outcomes update=Provost rewrites method episode=a module

The reward function

r(s, a) — graded on your learning, not your comfort.

Every outcome is a scalar reward to the teacher. The student's reward is always zero — they're the environment, never the one being penalized.

Event in the environmentRecipientReward
Student answers a probe correctlyteacher+1
Student passes a quizteacher+2
Student passes a unit examteacher+5
Semester finished with masteryteacher+20 ⟂
Student can't answer a probeteacher−1
Student fails a quizteacher−2
Student fails a mid-termteacher−10 ↺
Attendance / momentum stallsteacher−0.5
Any event, to the studentstudent0

Why one-sided?

If failure cost the student, they'd disengage — the opposite of learning. Putting the whole gradient on the faculty makes the system relentlessly accountable to the learner.

⟂ terminal reward · ↺ triggers re-enroll + policy update

Σ reward over a unit < threshold → escalate to Provost for a policy update.
The learning step

Low reward → the policy improves.

There's no gradient descent on weights here. The "update" is a rewritten methodology from the Provost — a structured change to how the agent teaches, applied through the Update Hook.

policy v3 · grade fell to C−
  • One dense blog per concept
  • Abstract-first, theory before practice
  • Probe immediately after reading
  • Uniform pace for all units
⟶Provost
rewrites
policy v4 · applied
  • Split each concept into 3 short blogs
  • Concrete example first, theory second
  • Worked practice before any probe
  • Slow the failing unit; add revision

Lifecycle · the heartbeat

One step of the loop, in time.

The agent wakes on a heartbeat or an event, runs one decision, acts, and sleeps — picking up exactly where it left off.

0

Idle

Asleep until a heartbeat or a subscribed event fires.

1

Observe

Pull the latest student model & curriculum position.

2

Deliberate

Policy chooses the next teaching action.

3

Act

Publish a blog, ask a probe, set work, or run a tool.

4

Reward

Outcome arrives; grade updates; memory is written.

5

Update?

If Σreward is low, request a new policy, then idle.
